# Plaso System.evtx fixture

- Original: <https://github.com/log2timeline/plaso/blob/1e2fa282efa2f839e1f179a3e98dbf922b5dbbc7/test_data/System.evtx>
- Local file: `src/formats/testing/plaso-system.evtx`, byte-identical to upstream Git blob `70f50e5d058ee8db3d4ee94c108eb7ad556977ac` (1,118,208 bytes).
- The python-evtx [test-data provenance](https://github.com/williballenthin/python-evtx/blob/master/tests/data/readme.md) independently attributes its same-hash system.evtx to Plaso at this commit.
- Repository license: Apache-2.0, <https://github.com/log2timeline/plaso/blob/1e2fa282efa2f839e1f179a3e98dbf922b5dbbc7/LICENSE>.
- Regression: `src/formats/evtx.test.ts` verifies the real file's chunk and record header inventory, byte identity, header and event-data CRC scopes (including a tampered record), registered inspect operation, and selected original BinXML bytes. `src/formats/evtxSubstitutions.test.ts` checks the first record's bounded inline-template substitution values against the independently published python-evtx record structure (including values 105, 820, 2868, and 12049), exports its exact 597-byte nested BinXML substitution, and decodes the nested indexed `System` and archive-path values. A second original record yields indexed nested `Windows Modules Installer`, `stopped`, and `38` values plus a 38-byte binary value, exported byte-exact without interpretation; a modified nested pointer is rejected after CRCs are recomputed. `src/formats/evtxTemplateNames.test.ts` checks CRC-gated candidate inline name records, including `EventID` and `TimeCreated` in the first record and `EventSourceName` in the second; a name corrupted with recomputed CRC is omitted. Candidate names are incomplete and are not mapped to substitutions or asserted as event fields. The raw FILETIME value truncates to `.354562` microseconds, while python-evtx rounds to `.354563`.

This is a published format fixture, not a sourced CTF challenge or proof of end-to-end EVTX payload decoding.
