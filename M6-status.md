# M6 status

Reference: `design.md` §5.2 and §6.2. This is a gap inventory, not an acceptance sign-off. The corpus has 17 attributed challenge YAML records, 14 with usable licensed fixtures; independently published format vectors live under `src/formats/testing/`. The M6 exit criterion requires each lab to reproduce its challenge corpus fixtures, and many lab families have no attributed challenge fixture yet.

The existing M6 additions include narrow readers and locally generated conformance vectors. A passing test on a generated vector does not establish support for every real-world variant of that format. The mail, EVTX, registry hive, ESE, Prefetch and Hayabusa JSONL vectors under `src/formats/testing/` provide independent real-file evidence, but do not satisfy any missing CTF challenge exit checks. The next acceptance work should prioritize independently produced fixtures and end-to-end challenge results over more header-only inventories.

Google CTF 2019 `sc` now has an original-capture regression from packet bytes through the independently reproduced bitmap to exact sparse glyphs `6Pool`; a convention-wrapped `CTF{6Pool}` candidate agrees with the official README flag. The glyph reader rejects a changed/missing point rather than guessing. This closes that challenge's plotted-text gap, not other lab-family corpus gaps.

Google CTF 2023 `Primes` now recovers the published flag from the original Sage attachment's embedded scrambled message and q/x constants: 381 bounded convergents, 135 indexed bit corrections, and exact re-encoding to x. This closes its earlier missing-message claim; the operation reports a verified candidate encoding, not mathematical uniqueness of the message.

Google CTF 2023 `Symatrix` now reconstructs all 272 mirrored-pixel bits from the original PNG and yields the published flag as an independently checked candidate. The operation does not take a flag or known text as input.

Google CTF 2023 `NPC` now discovers the published passphrase from the original `hint.dot` and full `USACONST.TXT` dictionary without taking it as input. The bounded search is non-exhaustive, but authenticating up to 16 of its candidates against the original 215-byte `secret.age` yields `CTF{S3vEn_bR1dg35_0f_K0eN1g5BeRg}` at scrypt work factor 19. The full dictionary-to-decryption chain passes as one pack-free operation in Chromium, Firefox and WebKit, as well as an original-fixture unit regression.

Google CTF 2018 `polyglot` now composes a single ZIP byte-identical to the published solution from both original ZIPs. Independent `7zz` extracts the first file set cleanly, while `unzip` extracts the correct second-set bytes but exits 3 with structural warnings. This establishes two payload views, **not** clean dual-extractor acceptance or the released flag; that acceptance gap remains open.

## Runtime packs (M6a)

The UI exposes download-for-offline and size metadata for Pyodide, sql.js, Wiregasm, Tesseract, Capstone, and threaded FFmpeg (plus bkcrack). `e2e/noEgress.spec.ts` checks that ordinary Base64 work fetches no pack and includes a cached-offline operation for each of the seven packs on Chromium/Firefox. WebKit offline reload checks are skipped: a retry after caching SQLite failed at navigation (`page.reload: WebKit encountered an internal error`), before the pack operation could run. This is **not** evidence of WebKit offline support.

`THIRD_PARTY_NOTICES.md` now records npm package integrities, installed Wiregasm/FFmpeg WASM hashes, the npm-reported upstream revisions and their build recipes. This technical trace does not prove exact binary/source correspondence or provide complete corresponding source to recipients; public distribution still requires a source-delivery method and licence-owner/legal approval.

Selected pack-free M6 UI flows (seccomp, format-string planning, Burp request diff, 7z Copy extraction, raw EVTX BinXML export from the original Plaso sample, RAR4/RAR5 stored-file extraction from published libarchive fixtures, Hayabusa JSONL timeline/entity import, ZIP-deflated sigrok session import, and bounded/resumed OTP swaps on the original 24-image subset plus a full 64-image run) pass in Chromium, Firefox and WebKit; this does not cover the remaining labs or offline pack reload on WebKit.
